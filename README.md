# LoL Arena Anvil Calculator

An unofficial fan-made calculator for the **League of Legends Arena** mode that compares anvil (stat upgrade) options and shows how each one changes your damage and survivability.

## Features

- Compare physical and magic damage scenarios side by side.
- Model attacker vs. target stats (AD/AP, armor, magic resist, lethality, penetration, damage reduction).
- Interactive chart of damage across target defence values, with a colour-blind-safe palette on a dark theme.
- Runs as a static HTML page or inside Streamlit.

## Tech stack

HTML · CSS · JavaScript · Python / Streamlit (host)

## Run

Open `index.html` in a browser, or:

```bash
pip install streamlit
streamlit run calculatorapp.py
```
